# 現行規則（試玩基準）

這份文件整理 herdr-reclaim **目前實作的規則與數值**。它們是 MVP 試玩基準，之後可能調整；數值改動時，以這份文件與 `mod/herdr-reclaim/core/rules.js` 為準。`docs/proposal.md` 是當時的設計提案與決策紀錄（已由 `docs/city-growth-replan.md` 取代），不保證與現況一致。

#22 之後只有**一座共用城市**：所有 repo、space 與 session 的工作都進同一個倉庫、同一張地圖。舊版各 repo 城的遠征格、開墾點、研究羊皮卷、市集、加速與舊蓋房已經移除；程式不再讀寫 `cities/`（磁碟上的舊目錄留著，不遷移）。

## 地圖

- 所有專案共用一座城。城鎮中心占 3×3 格，不能蓋其他建築。
- 開城揭開完整的 9×9 格；中心四邊中點各伸出 1 格道路。道路取代原地形，不能蓋建築。
- 起始庫存是木材 70、石材 35、鐵料 6。開城記下庫存、道路臂長、地形版本與種子；重開不會再發建材或換地圖。
- 新舊城的起始 9×9 地形相同。新城只在起始區外生成連續河道、湖泊、林帶與碎石礦脈；舊城全圖保留第一版地形。草地、疏林、碎石地可以蓋，深水與峭壁不行。村落距中心 12–18 格、市鎮 27–36 格各預留一處遺跡、礦脈與港灣，一般建築不可占用；目前沒有地標效果。
- **揭開**：一般建築完工時，占地往外 2 格永久揭開；哨站往外 5 格。看得見不等於可以蓋：除了哨站，整片占地每格都須在已通車道路的 3 格方圈內。城鎮中心不算道路，預定或施工中的道路也不算。
- 建築本身占著它的地，之後不能在上面再預定。
- **鋪路**（規則版本 16）：從已通車道路或中心邊緣選起點，再點已揭開且未占用的終點。只走四鄰，峭壁不能通行；限 12 個新格之內先比成本，再比步數，仍相同按北、東、南、西決定。舊路免費，新鋪陸地每格木 4、石 8；深水架橋每格木 20、石 40。預覽後確認，與建築共用佇列和付款規則。每兩個新格需一份工期，不足兩格算一份。通車後取代原地形，不揭地、不加維護。

## 共用城市的基本收入（#23）

同一份本機使用者資料共用一座城、一個倉庫：換 repo、space、`/new` 或恢復對話都不會另開工地，也不會改變收入。

- 有效工作的一段**已結束回合**（活動紀錄裡 `interval_open` 到 `interval_close`）累積到共用倉庫的工作計量器。判準：互動的 root 與互動 fork 算工作，`role=child` 的 session 併進它的 root；print／headless 不納入；只算 non-cache input + output；用量有未知欄位的回合整回合不計。有沒有 commit 都算，commit 不另外加碼（#28）。
- 每滿 **10,000** 有效 token 算一份工作，不足一份的餘數保留。每份由城鎮中心毛產木材 2、石材 1、鐵料 1。
- **維護**只從該份毛產扣 `0.5 × N / (N + 15)`，低於 50%。N 是已完工的實體建築數，缺人的也算；中心、道路、時代不算。各材小數留到下一份；沒工作不扣舊庫存。城市狀態相同時，切換對話或專案不會改變收入。
- **人口**：中心提供 2 人，每棟完工民居再加 4 人。頂欄顯示在職人力／人口容量。人力依完工順序分配：伐木場、採石場、市場需 2 人，工坊與書庫各 3 人，民居與哨站不需人力。不足時較晚完工的建築標「缺人」，補足即恢復。
- **產出建築**：有人運作才有毛產。伐木場產木、採石場產石、工坊產鐵，每份各產 1；占地外一圈（含斜角）的疏林、碎石地、碎石地或峭壁分別最多再加 3、3、2。已完工道路、未揭開格、建築與預定建築占地不算；同一格只歸最早完工的相符產場，即使已達上限也不轉給下一棟。中心與產場的毛產加總後才扣維護。
- **市場**：有 2 人運作才換料。施工線空出時先補手動隊首，再看下一棟自動建築；只用超過目標需求與隊首保留量的建材，以 2 換 1 補到缺額為止。換料跟當份收入一起記錄，建築清單按材料方向列出累計交換量。
- **人口解鎖**看容量，不看閒置人力：民居、伐木場、採石場、哨站從開城即可預定；市場需 14 人、工坊 22 人、書庫 42 人。人口達 86 且有書庫運作時，可手動預定一次升市鎮：不占新格，占一個佇列名額，輪到時付木 2600、石 2600、鐵 1300，施工 16 份。完工才解鎖大宅；大宅只可手動新建，完工增加 10 人。
- 同一份工作只入帳一次：兩支 session（或兩個 space、恢復對話後的新 epoch）回報同一個用量來源時，第二筆不重複發。不同工作即使 token 數與時間相同，仍是兩份。
- 共用城市從第一次啟用開始計收入；在那之前結束的回合不會倒灌（舊版各城歷史不遷移，見 #22）。

## commit 不另外收成（#28、ADR 0002）

commit 不另外收成，見 ADR 0002：收入只看工作量，有沒有 commit 都一樣。舊帳本裡已經落帳的成果收成照常重播（庫存不因改版改變），但不再產生新的（規則版本 9）。

## 選址與建設佇列（#25、ADR 0003）

- **先選建築、再看位置**：左側列出建築、整片占地、配方與完工揭開幾格。選好之後地圖標出全部合法錨點，點一格顯示整棟占地。
- **可建的地**：草地、疏林、碎石地。整棟占地每一格都必須已揭開、可建，而且沒有被其他建築、城鎮中心或佇列中的任何一項占住；任一角碰到深水、峭壁、迷霧或已占用的位置，整棟都不能放。同種建築在疏林、碎石地上的配方與工期與草地相同。
- **預覽就是下令**：畫面的整棟預覽與帳本的前提檢查用同一個判準，綠色代表下得了令，紅色那幾格就是不合法的那一角。
- **佇列上限 3 項**（含施工中的那一項）：滿了就擋新的預定，按「預定這裡」會用提示說明佇列已滿、要先騰出名額；完工或取消會釋出一個名額。還在排隊的項目彼此不擋，可以先規劃接下來幾棟。
- **指定位置不付料**：預定保留整片占地、庫存不預扣；缺料時照樣可以先排進佇列。排到隊首、庫存足以支付完整配方時才一次付清開工，畫面會寫「還缺」多少。
- **重開與跨 space**：佇列寫在共用帳本裡，切 repo、換 space、重開 herdr 或做 checkpoint 之後都一樣。

## 備料、施工與完工（#26、ADR 0003）

預定之後照常工作就好，不用回來按領取或確認完工。

- **一次只施工一項**：佇列依預定順序施工，只有最前面那一項在動工；其他的排隊，占地先保留、地面仍是原本的地形。
- **付款只在隊首**：哪一筆收入（基本收入，來自哪個專案、哪段對話都一樣）讓庫存足以支付隊首那一項的完整配方，就自動付清並開工。後面的項目不能插隊，所以排在前面那一項等的材料不會被後面的吃掉。
- **開工那一份不算工期**：每份先入庫，再讓原本的工地前進一份；完工釋出施工線後，付得起的隊首就開工。下令當下若施工線空著、材料已齊，也會立即付料開工。
- **建築表**（規則版本 18）：第 `n+1` 棟同種建築逐材取 `ceil(基礎 × 成長率ⁿ)`；民居成長率 1.12，三種產出建築 1.15，哨站 1.30，大宅 1.16。下令時計入前面已完工及已排定的棟次，配方隨預定固定。

| 建築 | 占地 | 配方 | 工期 | 完工揭開 |
|---|---|---|---|---|
| 民居 | 2×1 | 木材 20、石材 10、鐵料 6（基礎） | 14 份 | 2 格 |
| 伐木場 | 2×2 | 木材 50、石材 25（基礎） | 18 份 | 2 格 |
| 採石場 | 2×2 | 木材 60、石材 15（基礎） | 18 份 | 2 格 |
| 工坊 | 2×1 | 木材 60、石材 30（基礎） | 21 份 | 2 格 |
| 哨站 | 1×1 | 木材 25、石材 15、鐵料 5（基礎） | 4＋距最近已通車道路的方圈距離（下令時固定） | 5 格 |
| 大宅 | 2×2 | 木材 100、石材 85、鐵料 350（基礎） | 18 份 | 2 格 |
| 市場 | 2×2 | 木材 40、石材 20 | 12 份 | 2 格 |
| 書庫 | 2×2 | 木材 20、石材 20、鐵料 5 | 14 份 | 2 格 |

  沒有新進帳，工地就維持原狀。一次進帳多份會逐份推進，可以接連蓋完多棟。同種建築不因占地上的植被或碎石改變工期。
- **取消**：只能取消還沒開工的項目。那一項還沒付款，所以只是把占地與名額交還，庫存不動；已經開工就不能取消（配方已付、工地已動土）。
- **完工**：收到最後一份工期時立即啟用並揭開附近的土地；那一項離開佇列，下一項接著備料或開工。完工不另外付料。
- **只扣一次**：每筆工作進帳連同它推動的施工一次寫入。多個視窗重送、重開或重播，都不會再付料或推進同一份工期。
- **沿線自動施工（規則版本 15）**：手動項目優先，不打斷工地；隊首等料時，只可動用超過其完整配方的材料。自動項目不占手動佇列的三個名額。自動完工後的間隔預設為零份。
- 頂欄顯示「缺人／缺木／缺石／缺鐵」。人口扣除所有工作所需人力後不足 3，先蓋民居；否則用手動隊首的配方判斷最缺材料。沒有隊首時，村落看升市鎮配方（木 2600、石 2600、鐵 1300），市鎮看下一棟住宅。各材依配方缺口除以每份淨產排序，平手依木、石、鐵。先找有對應資源的產場，都不適合才蓋民居。
- 建築占地**每一格**距最近道路至多 3 格（方圈距離），城鎮中心不算道路。選址優先保留產量、少蓋掉資源與主軸；選好了但付不起就等料，蓋滿則提示「路旁沒有可蓋的地」。
- 地圖上三種狀態畫法不同：排隊中的預定地是強調色虛線（地面仍是原本的地形），施工中是工作色斜線與「施工·」標籤，完工是完成色實線、建築與名稱。

## 額度

- 只顯示 provider 或 CLI 明確回報的數字（`omp usage --json --redact` 的輸出）；拿不到、沒有回報項目、帳號沒有額度或資料過期，都顯示「未知」。不推算、不填 0 或 100，也不因額度擋住你。
- 額度是帳號層級、所有 workspace 共用：`quotas.json` 與「上次嘗試時間」都是全域檔案，不管開幾個視窗，每 5 分鐘最多查一次；按「更新額度」可以立刻抓。
- 只有開發模式顯示左側的「行會人力（provider 回報）」、更新按鈕與更新結果；不影響城市進帳。

## 舊版 git hook（#28）

舊版會在 repo 裝三個記錄器（`post-commit`、`post-merge`、`post-rewrite`），用來換取 commit 加碼。新版不再安裝、也不再收成；記錄器已在 2026-11-25 一次性移除，產品不提供清理介面。若某個 repo 還留著記錄器，它只會在本機記一筆並以 exit 0 結束，不影響 commit，也不再換成資源。
