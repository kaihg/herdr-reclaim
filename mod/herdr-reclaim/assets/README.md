# assets/

herdr-reclaim 的圖片素材。**這個資料夾與 repo 其他部分授權不同。**

| 範圍 | 授權 |
|---|---|
| 程式碼（repo 其他部分） | [MIT](../../../LICENSE) |
| 本資料夾內的圖片與其來源紀錄 | [CC BY 4.0](LICENSE) |
| 本資料夾內的字型（若有） | 各自附 OFL 等授權檔，不適用上面兩者 |

使用圖片時請標示：`herdr-reclaim contributors, CC BY 4.0`，並附上 `https://github.com/kaihg/herdr-reclaim`。

## 這些圖怎麼來的

圖片由 AI 圖像模型（ChatGPT 的圖像生成）依文字 prompt 生成，**作者沒有手動修改圖片**；需要調整時是回頭對模型下新的 prompt。完整的來源紀錄在 [`SOURCES.md`](SOURCES.md)，prompt 保存在 [`prompts/`](prompts/)。

## 權利聲明

請先閱讀 [`NOTICE.md`](NOTICE.md)：AI 生成的圖片在許多法域可能不受著作權保護，授權只在「作者實際擁有權利的範圍內」成立，且不保證沒有第三方權利。

## 新增圖片時

1. 圖放在這個資料夾（可分子資料夾）。
2. 在 `SOURCES.md` 新增一列（工具、模型、日期、prompt 檔、方案、人工修改、狀態）。
3. prompt 原文存成 `prompts/<圖片名稱>.prompt.txt`。
4. prompt 規則見 `NOTICE.md` 的「prompt 規則」。
