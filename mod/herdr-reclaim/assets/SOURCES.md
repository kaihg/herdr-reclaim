# 圖片來源紀錄

每張圖片一列。AI 生成的圖沒有來源紀錄就不要放進 repo。

| 欄位 | 說明 |
|---|---|
| 檔案 | 相對於 `assets/` 的路徑 |
| 日期 | 生成日期（YYYY-MM-DD） |
| 工具／模型 | 例如 ChatGPT 圖像生成；能看到模型名稱時一併填 |
| 方案 | 當時的帳號方案（Free／Plus／Pro／Team…） |
| 條款版本 | 當時適用的 OpenAI Terms of Use 生效日 |
| prompt | `prompts/` 底下的檔案 |
| 人工修改 | 預設「無」。作者不手動修改；調整是回頭下新 prompt，記在 prompt 檔裡 |
| 備註 | 例如參考了哪張既有素材、為何重生成 |
